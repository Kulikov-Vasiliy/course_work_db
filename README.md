# course_work_db
Курсовая работа по теме "Поиск вакансий с подключением БД"
## О проекте
Проект сделан в рамках курсовой работы по работе с базами данных с использованием Python-языка для закрепления знаний
## По установке:
  * Для PyCharm:
    1. клонировать репозиторий, введя в терминале git clone 
    2. установить зависимости через активированное виртуальное окружение: poetry install
  * Для GitHub:
    1. на странице проекта на кнопке <> Code открыть выпадающий список
    2. выбрать download zip или клонировать через ссылку https или ssh
## По применению проекта:
1. открыть модуль main через pycharm
2. сделать пробег у current file/комбинацией shift + f10/командой python src\main в терминале
## Дополнительно
В функционал проекта входит:
1. базовые классы содержат общие методы для классов и подклассов
2. Vacancies - основной набор функций
3. класс HeadHunterAPI - класс, подключающийся к платформе headhunter и получающая вакансии
4. класс JSONSaver - класс для сохранения в файл и удаления из него вакансий по определенному критерию (пока в сырой)
5. модуль utils - дополняет основную функциональность фильтрациями, сортировкой и ограничением вывода (сколько желает вывести пользоваетль)
6. main, будучи пусковым модулем, запускает код основного интерфейса взаимодействия с пользователем
7. модуль config - распаковка данных из .ini-файла, с помощью которых устанавливается связь с postgresql
8. модуль connect_db - подключение, создание бд и создание таблиц
9. класс DBManager - "класс-ручка", роль которого запись данных в таблицу, работа с ними. В текущей реализации:
  - get_companies_and_vacancies_count — получает список всех компаний и количество вакансий у каждой компании.
  - get_all_vacancies — получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
  - get_avg_salary — получает среднюю зарплату по вакансиям.
  - get_vacancies_with_higher_salary — получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.
  - get_vacancies_with_keyword — получает список всех вакансий, в названии которых содержатся переданные в метод слова, например python.
